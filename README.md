```

 사용자 화면은 메인화면에 고래이미지 하나 상단 우측에 텍스트로 (로그인/로그아웃 )
 관리자 화면은 로그인한 후 사용자 목록 / 추가 / 수정 / 삭제 / 상세보기 / 목록은 페이징 처리

- JDK21, gradle, 설정은 yaml 사용, lombok 사용
- modulith방식, event방식, CQRS 적용
- record사용 및 입력값 검증
- JPA 사용과 페이징 처리
- DB는 SQLite 사용
- 예외처리
- 데이터지향으로 만들어줘
- modulith 방식 통합 test 추가
- UI는 Thymeleaf
-  spring security를 사용하되 코멘트 처리해줘
```
